# 🐱 Cats vs Dogs Image Classification

A Computer Vision project that classifies images as **Cat** or **Dog** using **Transfer Learning** with **ResNet18**, **PyTorch**, and **Streamlit**.

---

## 📌 Features

- Image Classification
- Transfer Learning using ResNet18
- Streamlit Web Application
- Upload Images
- Confidence Score
- Class Probabilities

---

## 🛠️ Tech Stack

- Python
- PyTorch
- TorchVision
- Streamlit
- Pillow
- NumPy

---

## 📊 Model

- Model: ResNet18
- Technique: Transfer Learning
- Framework: PyTorch
